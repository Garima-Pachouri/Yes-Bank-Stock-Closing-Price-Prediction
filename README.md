# Yes Bank Stock Closing Price Prediction

## Project Overview
This project predicts the monthly closing stock price of Yes Bank using historical stock price data. The project includes data understanding, data cleaning, exploratory data analysis, feature engineering, model building, model evaluation, and final model selection.

## Problem Statement
The objective is to build a machine learning regression model that can predict the closing price of Yes Bank stock based on features such as Open, High, and Low prices.

## Dataset
The dataset contains monthly Yes Bank stock prices with the following columns:

- Date
- Open
- High
- Low
- Close

## Steps Performed
- Imported required Python libraries
- Loaded and understood the dataset
- Checked missing values and duplicate values
- Performed exploratory data analysis
- Created 20 meaningful charts with business insights
- Handled date column and created time-based features
- Applied feature scaling
- Built regression models
- Compared model performance
- Selected the best model
- Saved and loaded the final model for future prediction

## Machine Learning Models Used
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor / Gradient Boosting Regressor

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score

## Conclusion
The final model was selected based on the best evaluation scores. This project shows how machine learning can be used to analyze stock price trends and predict future closing prices.
